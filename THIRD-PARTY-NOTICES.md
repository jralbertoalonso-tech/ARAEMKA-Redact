# ARAEMKA Redact — componentes de terceros

ARAEMKA Redact incorpora componentes de terceros. Cada componente conserva su
autoría, marcas y licencia. Esta relación informativa no sustituye los textos
de licencia que acompañan a los paquetes instalados o a los portables.

| Componente | Uso | Licencia declarada | Origen |
|---|---|---|---|
| FastAPI | API local | MIT | https://github.com/fastapi/fastapi |
| Uvicorn | Servidor local | BSD-3-Clause | https://github.com/Kludex/uvicorn |
| python-multipart | Recepción de archivos | Apache-2.0 | https://github.com/Kludex/python-multipart |
| Microsoft Presidio | Orquestación de detección | MIT | https://github.com/microsoft/presidio |
| spaCy | Reconocimiento de entidades | MIT | https://github.com/explosion/spaCy |
| `es_core_news_md` | Modelo lingüístico español | GPL-3.0 | https://github.com/explosion/spacy-models |
| `en_core_web_md` | Modelo lingüístico inglés | MIT | https://github.com/explosion/spacy-models |
| PyMuPDF / MuPDF | Lectura y redacción de PDF | AGPL-3.0 / licencia comercial | https://github.com/pymupdf/PyMuPDF |
| python-docx | Documentos Word | MIT | https://github.com/python-openxml/python-docx |
| openpyxl | Libros Excel | MIT | https://foss.heptapod.net/openpyxl/openpyxl |
| pytesseract | Integración de OCR | Apache-2.0 | https://github.com/madmaze/pytesseract |
| Tesseract OCR y `tessdata` | OCR local | Apache-2.0 | https://github.com/tesseract-ocr/tesseract |

| ItsDangerous | Firma de sesión local | BSD-3-Clause | https://github.com/pallets/itsdangerous |

| PyInstaller | Construcción de portables | GPL-2.0-or-later con excepción de distribución | https://github.com/pyinstaller/pyinstaller |

Los modelos opcionales ejecutados mediante Ollama o LM Studio no se distribuyen
con ARAEMKA Redact. Su descarga y uso se rigen por la licencia del modelo que
elija cada usuario.

Durante la construcción de los portables se conservan además los avisos y
archivos de licencia disponibles en los paquetes instalados. Para consultar el
texto de una licencia concreta, use el repositorio de origen indicado o el
directorio de licencias incluido en el paquete.
