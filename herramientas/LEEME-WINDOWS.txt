ANONIPRO PARA WINDOWS
=====================

1. Descomprime TODO el archivo ZIP en una carpeta.
2. Haz doble clic en AnoniPRO.exe.
3. Deja abierta la ventana negra mientras utilizas la aplicación.

El navegador se abrirá automáticamente. El primer arranque puede tardar hasta
un minuto. Para cerrar AnoniPRO, cierra la ventana negra.

OCR INCLUIDO
------------
El reconocimiento de documentos escaneados e imágenes está incluido para
español e inglés. No hace falta instalar Tesseract ni configurar nada.

PRIVACIDAD
----------
Todo el procesamiento ocurre dentro de este ordenador. Los documentos no se
envían a internet y permanecen únicamente en memoria durante la sesión.

AVISO DE WINDOWS SMARTSCREEN
----------------------------
Esta edición todavía no lleva una firma digital Authenticode. Por eso Windows
puede mostrar «Windows protegió su PC» aunque el archivo sea legítimo.

Antes de abrirlo, verifica que el ZIP procede del canal oficial de AnoniPRO y
que su SHA-256 coincide con el archivo .sha256.txt publicado junto a él. Para
comprobarlo desde PowerShell:

  Get-FileHash .\AnoniPRO-portable-windows-x64-v*.zip -Algorithm SHA256

Si el valor coincide, en el aviso de SmartScreen elige «Más información» y
después «Ejecutar de todas formas». No continúes si el valor no coincide.

Una firma creada por el propio autor (autofirmada) no elimina este aviso y no
aporta confianza pública. Una firma Authenticode pública permite comprobar el
editor y acumular reputación, aunque las primeras descargas todavía pueden
mostrar el aviso. La distribución mediante Microsoft Store es la única opción
que evita de forma fiable el aviso de descarga de SmartScreen.

CONTENIDO DE LA CARPETA
-----------------------
AnoniPRO.exe inicia la aplicación. La carpeta _internal contiene sus modelos,
bibliotecas y el motor OCR; no debe borrarse ni separarse del ejecutable.
