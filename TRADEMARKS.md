# Marcas

ARAEMKA y ARAEMKA Redact, así como sus logotipos, son signos distintivos
reivindicados por el autor del proyecto. La licencia GNU AGPL del software no
concede derechos sobre estos signos, salvo el uso descriptivo necesario para
identificar el programa y conservar sus avisos de atribución.

Existen solicitudes españolas pendientes para la marca denominativa ARAEMKA y
para el logotipo figurativo completo. La solicitud figurativa `M4402483` fue
presentada el 13 de septiembre de 2026. Ninguna de estas solicitudes equivale
todavía a una concesión registral.

No debe utilizarse el símbolo ® mientras la marca no haya sido concedida por la
oficina competente.
